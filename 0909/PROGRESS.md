## L0 측정 결과 — B1 이 답을 얻었다

커밋 `22600b3`. 200종목 · 130만 행 직접 측정, 160초. 밴드는 `criteria.py` 에서
프로그램으로 읽어왔다(손으로 옮기지 않았다).

### 측정 신뢰성 — 대조군이 통과했다

사전등록 §4 가 요구한 조건이다. **L1·L5 의 직접 측정이 둘 다 밴드 안**에 들었다.

```
L1 직접   Spearman 0.997, 홀함수 오차 0.257 (밴드 0.3)      통과
L5 직접   멱함수, 곡률마진 0.700 (밴드 0.03)               통과
```

합성 데이터 검산 7종도 전부 통과했다 — γ=0.5 로 만든 가짜 데이터에서 0.5 가
나오고, 짝함수는 L1 에서 탈락하고, `criteria.py` 가 문서화한 "순수 직선 가짜통과"
함정은 곡률 검사가 정확히 걸렀다.

다섯 개가 전부 밴드 밖이었다면 측정 코드를 의심해야 했는데, 그렇지 않다.

### 결과 — 세 법칙 모두 밴드 밖 (a)·(b) 양쪽에서

| | (a) 직접 200종목 | (b) E0 표본 | 밴드 | 사전등록 §3 판정 |
| --- | --- | --- | --- | --- |
| L2 | CV **0.704** (기울기 +0.021, 부호는 맞음) | CV 0.337 | ≤ 0.15 | 밖/밖 → **게이트 기준이 틀림** |
| L3 | 지수 **0.078**, log-log R² **0.025** | 지수 0.065, R² 0.018 | [0.4,0.7], R²≥0.6 | 밖/밖 → **게이트 기준이 틀림** |
| L4 | 선형 R² **0.335**, 계수 전부 양수 아님 | R² 0.432 | ≥ 0.85 | 밖/밖 → **게이트 기준이 틀림** |

L3 는 예측보다 나빴다. "지수가 틀렸다"가 아니라 **멱법칙 관계 자체가 없다**
(log-log R² 0.025). 75만 행에서 잰 값이다.

### ★ 5개 전부 일치한다 — 이것이 이번 측정의 핵심

```
법칙이 데이터에 실제로 있는가        증류가 찾았는가
(L0 직접 측정)                      (E0 게이트)
--------------------------------------------------------
L1   있음 ✓                    →    복원 ✓  (홀함수 오차 1e-15)
L5   있음 ✓                    →    복원 ✓  (시드 4개 중 3개)
L2   없음 ✗                    →    실패 ✗
L3   없음 ✗                    →    실패 ✗
L4   없음 ✗                    →    실패 ✗
```

**증류는 데이터에 실제로 존재하는 법칙을 정확히 둘 다 찾아냈고, 존재하지 않는
법칙 셋에서 정확히 실패했다.** 우연히 맞은 것도, 있는데 놓친 것도 없다.

→ B1 의 답: **방법론(증류)의 문제가 아니다. 게이트가 이 데이터에 없는 법칙을
  찾아오라고 요구하고 있었다.**

### 부수 발견 — 게이트가 재는 것과 법칙이 주장하는 것이 다르다

`judge_l4` 의 회귀 타깃이 `g_full`, 즉 **SR 수식 자신의 출력**이다. 실제 `y` 가
아니다. `judge_l2`(`approximately_affine`)·`judge_l3`(`grid_eval`)도 같은 구조다.

```python
g_full = full_eval(expr, names, X[finite_rows])   # 수식을 평가한 값
target = g_full[finite_g]                          # ← 회귀 타깃이 이것
coef, *_ = np.linalg.lstsq(design, target, ...)
```

즉 세 판정은 **"발견된 수식이 교과서 법칙처럼 생겼는가"** 를 묻지
**"교과서 법칙이 이 데이터에서 참인가"** 를 묻지 않는다.

복원 실험의 설계로는 이것이 옳다 — 형태 일치를 보는 것이 목적이다(L1·L5 가
그렇게 작동하고 실제로 판별력이 있다). 그러나 그 설계는 **법칙이 데이터에
있다는 전제** 위에서만 뜻이 있고, 그 전제를 이제 잰 것이다.

E0 가 L4 에서 보고한 R²=0.981 은 그래서 "예측력이 좋다"가 아니라 "그 수식이
세 스케일의 선형결합에 가깝다"는 뜻이었다. 실측 y 로 직접 재면 0.335 다.

### 남은 의문 (정직하게 기록)

- **L1·L5 의 (b) E0 표본 측정은 밴드를 벗어났다.** 표본이 130만 → 7,900행으로
  줄면서 잡음이 커진 것인지, on-manifold 표집 자체의 왜곡인지 이 측정만으로는
  못 가린다. 사전등록이 신뢰 조건으로 명시한 것은 (a) 직접 측정이었고 그건
  통과했으며, L2·L3·L4 는 (a)에서 이미 크게 밴드 밖이라 결론은 흔들리지 않는다.
  다만 **E0 표본에서 L1 이 밴드 밖인데 증류는 L1 을 복원했다**는 것은 설명이
  필요하다 — 다음 작업 후보다.
- L3 는 log(0) 회피로 표본이 41% 줄었다(틱 데이터에 정확히 0인 수익률·부호거래량이 흔하다).
