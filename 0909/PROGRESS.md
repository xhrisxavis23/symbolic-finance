## L0 측정 결과 — B1 이 답을 얻었다

커밋 `22600b3`. 200종목 · 130만 행 직접 측정, 160초. 밴드는 `criteria.py` 에서
프로그램으로 읽어왔다(손으로 옮기지 않았다).

### 측정 신뢰성 — 대조군이 통과했다

사전등록 §4 가 요구한 조건이다. **L1·L5 의 직접 측정이 둘 다 밴드 안**에 들었다.

```
L1 직접   Spearman 0.997, 홀함수 오차 0.257 (밴드 0.3)      통과
L5 직접   멱함수, 곡률마진 0.700 (밴드 0.03)               통과
```

합성 데이터 검산 7종도 전부 통과했다 — γ=0.5 로 만든 가짜 데이터에서 0.5 가
나오고, 짝함수는 L1 에서 탈락하고, `criteria.py` 가 문서화한 "순수 직선 가짜통과"
함정은 곡률 검사가 정확히 걸렀다.

다섯 개가 전부 밴드 밖이었다면 측정 코드를 의심해야 했는데, 그렇지 않다.

### 결과 — 세 법칙 모두 밴드 밖 (a)·(b) 양쪽에서

| | (a) 직접 200종목 | (b) E0 표본 | 밴드 | 사전등록 §3 판정 |
| --- | --- | --- | --- | --- |
| L2 | CV **0.704** (기울기 +0.021, 부호는 맞음) | CV 0.337 | ≤ 0.15 | 밖/밖 → **게이트 기준이 틀림** |
| L3 | 지수 **0.078**, log-log R² **0.025** | 지수 0.065, R² 0.018 | [0.4,0.7], R²≥0.6 | 밖/밖 → **게이트 기준이 틀림** |
| L4 | 선형 R² **0.335**, 계수 전부 양수 아님 | R² 0.432 | ≥ 0.85 | 밖/밖 → **게이트 기준이 틀림** |

L3 는 예측보다 나빴다. "지수가 틀렸다"가 아니라 **멱법칙 관계 자체가 없다**
(log-log R² 0.025). 75만 행에서 잰 값이다.

### ★ 5개 전부 일치한다 — 이것이 이번 측정의 핵심

```
법칙이 데이터에 실제로 있는가        증류가 찾았는가
(L0 직접 측정)                      (E0 게이트)
--------------------------------------------------------
L1   있음 ✓                    →    복원 ✓  (홀함수 오차 1e-15)
L5   있음 ✓                    →    복원 ✓  (시드 4개 중 3개)
L2   없음 ✗                    →    실패 ✗
L3   없음 ✗                    →    실패 ✗
L4   없음 ✗                    →    실패 ✗
```

**증류는 데이터에 실제로 존재하는 법칙을 정확히 둘 다 찾아냈고, 존재하지 않는
법칙 셋에서 정확히 실패했다.** 우연히 맞은 것도, 있는데 놓친 것도 없다.

→ B1 의 답: **방법론(증류)의 문제가 아니다. 게이트가 이 데이터에 없는 법칙을
  찾아오라고 요구하고 있었다.**

### 부수 발견 — 게이트가 재는 것과 법칙이 주장하는 것이 다르다

`judge_l4` 의 회귀 타깃이 `g_full`, 즉 **SR 수식 자신의 출력**이다. 실제 `y` 가
아니다. `judge_l2`(`approximately_affine`)·`judge_l3`(`grid_eval`)도 같은 구조다.

```python
g_full = full_eval(expr, names, X[finite_rows])   # 수식을 평가한 값
target = g_full[finite_g]                          # ← 회귀 타깃이 이것
coef, *_ = np.linalg.lstsq(design, target, ...)
```

즉 세 판정은 **"발견된 수식이 교과서 법칙처럼 생겼는가"** 를 묻지
**"교과서 법칙이 이 데이터에서 참인가"** 를 묻지 않는다.

복원 실험의 설계로는 이것이 옳다 — 형태 일치를 보는 것이 목적이다(L1·L5 가
그렇게 작동하고 실제로 판별력이 있다). 그러나 그 설계는 **법칙이 데이터에
있다는 전제** 위에서만 뜻이 있고, 그 전제를 이제 잰 것이다.

E0 가 L4 에서 보고한 R²=0.981 은 그래서 "예측력이 좋다"가 아니라 "그 수식이
세 스케일의 선형결합에 가깝다"는 뜻이었다. 실측 y 로 직접 재면 0.335 다.

### 남은 의문 (정직하게 기록)

- **L1·L5 의 (b) E0 표본 측정은 밴드를 벗어났다.** 표본이 130만 → 7,900행으로
  줄면서 잡음이 커진 것인지, on-manifold 표집 자체의 왜곡인지 이 측정만으로는
  못 가린다. 사전등록이 신뢰 조건으로 명시한 것은 (a) 직접 측정이었고 그건
  통과했으며, L2·L3·L4 는 (a)에서 이미 크게 밴드 밖이라 결론은 흔들리지 않는다.
  다만 **E0 표본에서 L1 이 밴드 밖인데 증류는 L1 을 복원했다**는 것은 설명이
  필요하다 — 다음 작업 후보다.
- L3 는 log(0) 회피로 표본이 41% 줄었다(틱 데이터에 정확히 0인 수익률·부호거래량이 흔하다).
- 하루치(20260316), 시드 하나다.

### 내가 지적한 구멍의 처리 — 정확하다

"단순 회귀가 못 찾는 걸 증류가 찾으면 오답 되는 문제"에 대해:

참조 천장을 **"참조 방법의 형태"가 아니라 "이 데이터 이 타깃에 잡히는 신호가
얼마나 있는가"** 로 정의했다. 그래서 증류가 비선형·교호 관계를 찾아 실제 R² 가
천장보다 높으면 **통과이자 특기 사항**이 된다. 형태를 강제하는 것은 진단(A)뿐이고
그건 판정에 안 쓴다.

남는 위험(진짜 관계가 단순 회귀로 아예 안 잡히면 자격 검사에서 조기 배제)도
"완전한 해법이 없다"고 명시하고 완화책(문턱을 0으로 고정, 자격 미달도 점추정
항상 보고)을 붙였다.

## G2 민감도 확인 결과와 코디네이터 판정 (R30)

커밋 `f278859`, `f808a8b`. 조건(R29) 이행 과정에서 **진짜 버그 두 개를 더 잡았다.**

### L1 — 내 가설도 설계자 가설도 틀렸다. 원인은 종목 수가 아니었다

배관 확인에서 "참조 집합이 작으면 L1 CI 가 흔들린다"고 봤고, 그래서 나는 층당
15/20/25 민감도를 지시했다. **둘 다 틀렸다.**

원인은 `sd.manifold.select` 의 **표집 상한(4000)** 이었다. 종목을 늘려도 행이
상한에 걸려 안 늘어나므로 규모를 키운 효과가 없었다. 참조 측정에만 상한을
분리(20000)하니:

```
CI 하한 스프레드   0.464  →  0.030   (15배 안정)
행 수              ~4,000 → ~19,800  (5배)
층당 15/20/25 전부 자격 있음
```

**"규모가 작아서"라는 진단이 맞았다면 종목을 늘렸을 때 안정됐어야 하는데
안 그랬다.** 상한이라는 다른 원인이 있었다. 민감도 확인을 지시하지 않았으면
못 찾았을 것이고, 전체 실행의 판정이 이 상한의 산물이 될 뻔했다.

### L5 — 블로업은 고쳤고, 불안정은 남았다

먼저 진짜 버그: L5 참조 모델이 멱함수 항을 `dt`→0 으로 외삽해 발산했다.
층당 20 에서 `CI = [-53,145,152,218.76, -841.80]` — 530억. 정의역 클리핑으로 고쳤다.

고친 뒤에도 자격이 비단조로 뒤집힌다:

```
cap  4000:  층당15 없음 / 층당20 **있음** / 층당25 없음
cap 20000:  층당15 **있음** / 층당20 없음 / 층당25 **있음**
```

규모를 키우면 나아지는 패턴이 아니다. 설정에 따라 사실상 무작위로 뒤집힌다.

### ★ 세 갈래 증거가 같은 것을 가리킨다

L5 의 불안정은 이번 설계의 문제가 아니라 **이 데이터에서 L5 의 성질**이다.
서로 독립인 세 방법이 전부 같은 말을 한다:

```
L0 직접 측정      전체 풀에서는 통과, E0 표본(7,900행)에서는 실패
증류(E0)          시드 4개 중 3개 복원
G2 참조 측정      설정 6개 중 4개 자격, 비단조
```

L5 는 **있지만 약하게·불안정하게 잡히는 법칙**이다.

Ruling R30 (L5 를 대조군에서 내리고, 잃은 방어를 음성 대조군으로 메운다):
  설계자는 세 선택지(참조 집합 더 키우기 / L5 참조 모델 재설계 / L5 를 대조군에서
  제외)를 제시하고 **고르지 않았다.** 결과를 보고 고르면 이 설계가 막으려 한
  순환에 스스로 빠진다는 이유였다. 옳은 판단이다. 그래서 내가 정한다.

  **결정:**
  (1) **L1 을 유일한 양성 대조군으로 한다.** CI 하한 스프레드 0.030 으로 안정적이고
      층당 15/20/25 전부 자격이 있다.
  (2) **L5 는 대조군에서 내려 채점 대상 법칙으로 옮긴다.** 불안정 자체를
      1급 결과로 보고한다 — 숨기지 않는다.
  (3) **참조 집합을 L5 가 통과할 때까지 키우지 않는다.** 그것이 결과에 맞춰
      설정을 고르는 것이다. 비단조로 뒤집히므로 어차피 안 통한다.
  (4) **잃은 방어를 음성 대조군으로 메운다.** 대조군이 하나로 줄면 "측정이
      고장났는데 L1 만 우연히 통과"하는 경우를 못 잡는다. 그래서 **실제 데이터에서
      y 를 섞은(permuted) 관계**를 넣어 그것이 반드시 **자격 없음**으로 나와야
      한다는 조건을 추가한다. 양성 하나 + 음성 하나가 양성 둘보다 강한 검사다.

  **이것이 사후 결정임을 명시한다.** 결과를 보고 정했다. 다만 결과에 맞춘 것이
  아닌 이유: 문턱을 낮춰 L5 를 통과시키지 않았고, 오히려 **더 엄격한 검사를
  추가**했다. L5 의 재분류 근거는 이번 실행이 아니라 **서로 독립인 세 방법의
  수렴**이다.
  틀렸을 때의 비용: 대조군이 하나(+음성 하나)라 측정 결함 탐지력이 이론상 약해진다.
  음성 대조군이 그 손실을 메우는지는 실측으로 확인해야 한다.

## ★ 음성 대조군이 L4 에서 허위 양성을 잡았다 (R30 ④의 성과)

`results/g2_negative_control.json`. y 를 섞은 관계 50회(법칙 5 × 섞기 2방식 × 5반복).
**전부 자격 없음이어야 정상이다.**

| 법칙 | 종목 내 섞기 | 전체 섞기 |
| --- | --- | --- |
| L1 | 0/5 (R² −2.63~−1.82) | 0/5 |
| L2 | 0/5 (−0.26~+0.14) | 0/5 |
| L3 | 0/5 (−762~−502) | 0/5 |
| **L4** | **5/5 자격 있음 (R² +0.810~+0.856)** ← 허위 양성 | 0/5 (−0.44~+0.15) |
| L5 | 0/5 (−0.37~−0.19) | 0/5 |

**L4 는 y 를 종목 안에서 완전히 섞어도 R² 0.85 가 나온다.** 신호가 없는데 있다고
말한다. 반면 전체 섞기에서는 자격이 안 나온다 — 이 대비가 원인을 지목한다.

**원인:** 종목 내 섞기는 **종목 간 수준 차이**를 보존한다. L4 참조 모델이 잡고
있던 것은 "같은 종목 안에서 다중 스케일 RV 가 미래 RV 를 예측한다"(법칙이 주장하는
것)가 아니라 **"종목마다 RV 수준이 다르다"** 는 횡단면 차이였다.

법칙이 주장하는 것과 측정이 재는 것이 또 어긋났다 — **E0 의 `judge_l4` 가
수식 자신의 출력을 회귀 타깃으로 쓴 것과 같은 종류의 오류**가, 그것을 고치려고
만든 G2 의 참조 측정에서 다시 나타났다.

Ruling R31 (L4 참조 측정에서 종목 수준 효과를 제거한다):
  L4 가 주장하는 것은 **종목 내 동적 관계**다(미래 RV ← 다중 스케일 RV).
  그러므로 참조 측정도 종목 수준 효과를 통제해야 한다 — 종목 내 중심화
  (within-symbol demeaning) 또는 종목 고정효과.
  **이것은 통과시키려는 조정이 아니라 정확성 수정이다.** 근거: 음성 대조군이
  "측정이 종목 간 차이를 종목 내 신호로 오인한다"는 것을 직접 보였다.
  **조건:** 수정 후 음성 대조군을 **다시 돌려 L4 가 0/5 로 떨어지는 것을 확인**한다.
  안 떨어지면 원인이 다른 데 있는 것이므로 다시 찾는다.
  같은 검사를 나머지 법칙에도 적용해, 수정이 다른 법칙의 양성 신호를 죽이지
  않는지 확인한다(L1 대조군이 여전히 자격을 유지해야 한다).
  틀렸을 때의 비용: 종목 내 중심화가 L4 의 진짜 신호까지 지울 수 있다.
  그 경우 L4 는 자격 없음으로 떨어지는데, 그것 역시 정직한 결과다 —
  L0 직접 측정에서도 L4 는 선형 R² 0.335 로 밴드(0.85) 밖이었다.

  ★ 이 발견의 의미: 내가 R30 ④에서 음성 대조군을 넣지 않았다면 G2 는
    **L4 에 대해 허위 양성을 내는 채로 전체 실행에 들어갔을 것이다.**
    양성 대조군(L1)만으로는 이걸 절대 못 잡는다 — L1 은 정상이기 때문이다.
    "양성 하나 + 음성 하나가 양성 둘보다 강하다"가 실측으로 확인됐다.

### 내 예측이 빗나갔다 — L4 는 살아남았다

R31 에서 나는 "L4 가 수정 후 자격 없음으로 떨어져도 정직한 결과다, L0 의 0.335 와
일치하는 셈"이라고 썼다. **틀렸다.** 종목 수준 교란을 제거해도 L4 는 자격을 유지한다.

행 단위 R² 는 L0 의 0.335 → 0.165 로 내려갔다 — 교란이 그만큼 부풀리고 있었다는
뜻이고 방향은 예상대로다. 그런데 0 보다 뚜렷이 크다.

의미: **L4 에는 진짜 종목 내 신호가 있다. 다만 교과서가 주장하는 크기가 아니다.**
E0/L0 의 밴드(0.85)는 "법칙이 교과서대로 성립하는가"를 물었고 그건 아니다.
G2 의 자격 검사는 "증류할 신호가 있는가"를 묻고 그건 맞다. **두 질문이 다르고
답도 다르다** — 이 구분이 G2 설계의 핵심이었음이 실측으로 확인됐다.

### 설계자가 자기 버그를 하나 더 잡았다

훨씬 크다)가 진짜 관계를 덮었다. 합성 검산이 직접 잡았다 — 진짜 강한 신호가 있는
데이터에서 R² = **−82**. 각 검정 종목 **자신의 X 평균**으로 중심화하도록 고치고
재검증(진짜 신호 0.997, 순수 교란 −4.9).
