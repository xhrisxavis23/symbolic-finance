# L0 — 법칙 직접 측정 결과

측정 실행: 2026-09-09. `PREREG-L0.md` 를 결과를 보기 전에 커밋한 뒤 **단 한 번** 돌렸다.
스크립트: `0909/l0_measure.py`. 원자료: `0909/results/l0_direct.json`.

**결론(한 줄):** L1·L5 대조군은 직접 측정(a)에서 밴드 안에 들었다 — 측정 코드는
신뢰할 수 있다. 그 신뢰할 수 있는 코드로 잰 L2·L3·L4 는 **셋 다 직접 측정(a)에서부터
이미 밴드 밖**이었다. 사전 예측("세 법칙 모두 게이트 기준이 이 데이터에 맞지
않는다")이 **맞았다** — 그것도 L3 는 예측보다 훨씬 더 나쁘게.

## 3. 법칙별 결과

밴드는 전부 `criteria.py` 에서 프로그램으로 읽었다(`read_bands()`) — 아래 표의
숫자는 손으로 옮기지 않았다.

### L2 — OFI 선형 (밴드: `slope_cv<=0.15`, `slope_mean>0`)

| | (a) 직접 | (b) E0 표본 |
| --- | --- | --- |
| 종목 수(기울기 산출) | 196/200 | 50/90 |
| 행 수(전체 유효) | 1,279,918 | 7,921 |
| 종목당 행 수(median) | 2,608 | 56.5 |
| slope_mean | **+0.0215** | **+0.0323** |
| slope_cv | **0.704** (기준의 4.7배) | **0.337** (기준의 2.2배) |
| 밴드 안? | **아니오** | **아니오** |

**판정(사전등록 §3 표): 밴드 밖 / 밴드 밖 → "법칙이 이 데이터에서 성립 안 함 →
게이트 기준이 틀림".** 부호는 양쪽 다 예측대로 양(+)이지만, 종목을 가로질러
하나의 β 를 공유한다는 가정이 이 데이터에서 성립하지 않는다. 참고로 E0
실행에서 보고된 CV 는 0.895(SR 후보 표현식의 도함수 항상성 기준)였다 — 방법이
다른데도 방향은 같다. E0 표본(b)의 CV(0.337)가 직접(a)의 CV(0.704)보다 낮다는
점은 흥미롭다 — 층화·on-manifold 표집이 종목간 이질성을 절반 가까이 줄이지만,
기준선(0.15)까지는 한참 못 미친다.

### L3 — 집계 임팩트 제곱근 (밴드: 지수 ∈ [0.4,0.7], log-log R² >= 0.6)

| | (a) 직접 | (b) E0 표본 |
| --- | --- | --- |
| 행 수(0 제외 후 / 0 제외 전) | 758,847 / 1,279,918 | 3,330 / 7,914 |
| 지수 | **0.078** | **0.065** |
| log-log R² | **0.025** | **0.018** |
| 밴드 안? | **아니오** (지수·R² 둘 다) | **아니오** (지수·R² 둘 다) |

**판정: 밴드 밖 / 밴드 밖 → "게이트 기준이 틀림".** 예측한 것보다 훨씬 나쁘다 —
예측은 "지수와 적합도가 동시에 밴드 안에 들지 않는다"(E0 처럼 하나는 맞고
하나는 틀리는 패턴)였는데, 직접 측정에서는 **둘 다 완전히 밴드 밖이고 R² 가
0.02~0.03 수준**이다. 이는 "|signed_volume/Q̄| 와 |ΔP/spread| 사이에 로그-로그
관계가 사실상 존재하지 않는다"는 뜻이다 — E0 가 실행마다 하나씩 맞춘 것은
증류·SR 이 만든 매끄러운 후보 표현식의 성질이었지, 원자료 자체의 성질이
아니었을 가능성이 높다.

### L4 — 다중 스케일 RV 결합 (밴드: 전역 R²>=0.85, 세 계수 모두 양수·|계수|>1e-6)

| | (a) 직접 | (b) E0 표본 |
| --- | --- | --- |
| 행 수 | 1,260,472 | 7,925 |
| 계수 (rv5, rv20, rv100) | (0.784, **−0.085**, 0.194) | (0.849, +0.055, 0.148) |
| 전역 R² | **0.335** | **0.432** |
| 전부 양수? | 아니오(rv20 음수) | 예 |
| 밴드 안? | **아니오** (R² 미달) | **아니오** (R² 미달) |

**판정: 밴드 밖 / 밴드 밖 → "게이트 기준이 틀림".** 20틱 계수의 부호은 표본에
따라 흔들린다(직접: 음수, E0표본: 작은 양수) — 예측("20틱 계수가 직접
측정에서도 0 근처이거나 음수")은 직접 측정(a)에서는 맞았다. 하지만 최종 판정을
가르는 것은 부호이 아니라 **전역 R²**다: 실측 forward RV20 을 세 스케일의
선형결합으로 설명하면 R²가 0.33~0.43 에 그친다.

**중요한 조작적 정의 차이.** E0 가 보고한 R²=0.981(`PROBLEMS.md` B1)은
`criteria.judge_l4` 가 **SR 후보 표현식 자체의 값**(`full_eval(expr,...)`)을
같은 세 feature 에 다시 회귀해 "그 표현식이 스스로 얼마나 선형에 가까운가"를
잰 것이다 — **실측 미래 RV 를 얼마나 잘 예측하는가가 아니다.** 이 L0 측정은
사전등록 §1 이 명시한 대로 **실측 `y_dimless`(미래 100틱 RV20-유사 추정량)**를
직접 세 스케일에 회귀했다. 두 R² 는 서로 다른 질문에 대한 답이고, 이 데이터에서
후자(진짜 예측력)는 훨씬 낮다. 이건 "왜 E0 의 L4 진단(R²=0.981, 계수 부호만
문제)이 낙관적이었는가"에 대한 설명이 될 수 있다 — 게이트가 표현식의 자기
선형성을 재고 있었지, 법칙의 예측력을 재고 있지 않았다.

## 4. L1·L5 대조군

### L1 — 마이크로프라이스 (밴드: Spearman |ρ|>=0.9, 홀함수 상대오차<=0.3)

| | (a) 직접 | (b) E0 표본 |
| --- | --- | --- |
| 행 수 | 1,298,583 | 7,917 |
| Spearman ρ | **0.997** | 0.881 |
| 홀함수 상대오차 | **0.257**(기준 0.3 이내) | 0.463 |
| 밴드 안? | **예** | 아니오 |

### L5 — Hawkes 커널 (밴드: R²>=0.7, 곡률마진>=0.03, decay_positive)

| | (a) 직접 | (b) E0 표본 |
| --- | --- | --- |
| 행 수 | 402,546 | 7,903 |
| 최적 형태 R² | **0.730**(power_law) | 0.603 |
| 곡률마진 | **0.700** | 0.572 |
| 밴드 안? | **예** | 아니오(R² 미달) |

**자기변호 위험 점검(사전등록 §4-2): 통과.** L1·L5 의 **직접(a)** 측정이 둘 다
밴드 안에 들었다 — "다섯 법칙이 전부 밴드 밖이면 측정 코드를 의심하라"는
사전 조건에 걸리지 않는다. 측정 코드가 실제로 참인 법칙(L1은 E0 4트랙 전부
복원, L5는 시드 4개 중 3개 복원)을 직접 데이터에서 올바르게 찾아낸다.

**동시에 우려할 점이 하나 있다.** L1·L5 모두 **(b) E0 표본에서는 밴드를
벗어난다.** (a)/(b) 대비 규칙을 그대로 적용하면 "밴드 안/밴드 밖 → E0 의
표집이 왜곡 → 파이프라인 문제"에 해당하는 패턴이 대조군에서도 나타난 것이다.
다만 이 스크립트가 세운 자기검증 기준은 어디까지나 "**직접** 측정이 밴드
안"이었고 그 기준은 통과했다 — (b)에서의 이탈은 두 가지로 읽을 수 있다:

1. E0 의 층화(90종목)+on-manifold 표집(법칙당 ~7,900행, 종목당 median ~56~65행)이
   표본 크기를 1,300,000행에서 7,900행으로 줄이면서 통계적 검정력이 떨어져,
   원래 경계 근처(L1 홀함수오차 0.257 vs 기준 0.3, L5 R² 0.730 vs 기준 0.7)에
   있던 법칙이 노이즈로 밴드를 넘어간 것일 수 있다(표본 축소 효과).
2. on-manifold 표집·층화 자체가 분포를 왜곡한 것일 수 있다(진짜 파이프라인
   문제).

이 스크립트만으로는 둘을 더 가르지 못한다 — 아래 "우려사항"에 남긴다. 다만
**L2·L3·L4 의 최종 판정에는 영향이 없다**: 이 셋은 (a) 직접 측정(1.3M 행,
표집·왜곡 가능성이 가장 적은 조건)에서부터 이미 밴드를 크게 벗어났으므로,
표본 축소나 표집 왜곡으로 설명되지 않는다.

## 5. 사전 예측과의 대조 (PREREG-L0.md §4)

| 법칙 | 예측 | 실측 | 예측 적중? |
| --- | --- | --- | --- |
| L2 | 직접 측정도 CV 가 0.15 를 크게 넘는다 | CV=0.704(직접), 0.337(E0표본) — 둘 다 크게 초과 | **적중** |
| L3 | 지수·적합도가 동시에 밴드 안에 들지 않는다 | 지수 0.07~0.08, R² 0.02~0.03 — 둘 다 완전히 밴드 밖 | **적중(예측보다 더 나쁘게)** |
| L4 | 20틱 계수가 직접 측정에서도 0 근처이거나 음수 | 직접: −0.085(음수, 적중) / E0표본: +0.055(작은 양수, 불일치). 다만 최종 판정은 R² 미달이 좌우 | **부분 적중** — 판정을 가른 축은 부호가 아니라 R² |

**세 법칙 모두 "게이트 기준이 이 데이터에 맞지 않는다"는 예측이 맞았다.**
예측이 틀렸을 경우의 결론("증류가 못 찾았을 뿐 법칙은 성립한다, B1을 닫고
방법 개선으로 간다")은 **기각된다.** L2·L3·L4 어느 것도 직접 측정에서
밴드 안에 들지 않았다.

## 6. 우려사항

1. **L1·L5 의 (b) 이탈을 표본 축소 효과와 표집 왜곡으로 분리하지 못했다.**
   둘 다 (a)에서 밴드 경계에 가까웠다(L1 홀함수오차 0.257/0.3, L5 R² 0.730/0.7)
   — 여유가 크지 않아 (b)의 표본 축소만으로도 경계를 넘어갈 수 있다. 시드를
   바꾸거나 (b)의 표본 크기를 (a) 수준으로 늘려 재확인하면 가를 수 있지만,
   사전등록 §5("결과가 나쁘면 다시 재기 금지")에 따라 이 실행에서는 하지
   않는다.
2. **L3 의 표본 손실이 크다.** log(0) 을 피하려 `signed_volume=0` 이거나
   `|y|=0` 인 행을 뺐더니 직접 측정에서 1,279,918→758,847행(41% 손실)으로
   줄었다. 틱 데이터에서 정확히 0인 20틱 수익률·부호거래량이 흔하다는
   뜻이고, 이 자체가 "제곱근 임팩트"라는 연속적 법칙과 이산적 호가 데이터의
   불일치를 보여주는 방증일 수 있다.
3. **L4 의 R²=0.335/0.432 는 실측 예측력이지 E0 가 보고한 0.981 이 아니다**
   (§3 L4 절 참고) — 두 수치를 직접 비교하면 안 된다. 이 차이 자체가
   "게이트가 재는 것과 법칙이 주장하는 것이 다르다"는 B1 의 핵심 의심을
   뒷받침한다.
4. **(a) 직접 풀(200종목, seed=0 무작위)과 (b) E0 풀(90종목, 6층×15)은
   종목이 겹칠 수 있다** — 원래 서로 다른 목적(전체 모집단 대표 vs E0 파이프라인
   재현)이라 배타적으로 설계하지 않았다. L2·L3·L4 의 (a)/(b) 판정이 둘 다
   밴드 밖으로 일치하므로 이 중첩이 결론을 바꾸지는 않는다.
5. **`sd.dimensionless` 모듈은 import 만 하고 실제로 호출하지 않았다** —
   `sd/e0/targets.py` 가 만드는 법칙별 무차원 X/y 는 그 모듈(`dimensionless.transform`,
   일반 SR 어휘 파이프라인 전용)을 타지 않고 직접 비율로 구성되기 때문이다
   (코드 확인, `l0_measure.py` 상단 NOTE 참고). 지시된 재사용 목록에 있어
   import 는 남겨 뒀다.
