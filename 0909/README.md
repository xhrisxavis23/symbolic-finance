# 0909 — 0902 에서 막힌 것을 푸는 작업 폴더

## 왜 이 폴더가 생겼나

0902 에서 심볼릭 증류 파이프라인을 만들고 E0 게이트(이미 답이 알려진 미시구조
법칙 5개를 재발견할 수 있는가)를 두 라운드 돌렸다. 결과는 두 번 다 `stop` 이다.

그런데 **왜 막혔는지**가 라운드마다 달랐고, 마지막에 남은 진단이 이렇다:

> 우리 방법이 부족한 것인지, 저 상수들이 이 데이터에서 성립하지 않는 것인지
> **구분할 수 없다.**

이 폴더는 그 구분을 짓고, 남은 표본 내 함정을 제거하는 작업의 기록이다.

## 이 폴더의 규칙

- **코드베이스는 여전히 `0902/` 다.** 파이프라인 수정은 거기에 들어간다.
  0909 는 **진단·측정·기록**을 담는다. 코드를 두 폴더로 쪼개면 어느 쪽이
  진짜인지 모르게 된다.
- 0909 의 진단 스크립트는 `0902/sd/*` 를 **읽기 전용으로 재사용**한다
  (`sys.path` 로 붙인다). 두 번째 진실 원천을 만들지 않는다.
- 상위 폴더(`/home/dgu/tick/tickdata_krx`, `/home/dgu/tick/proj_claude_tick_finance`)는
  **읽기 전용**. 날짜는 `20260316` 만. `20260317` 이후는 봉인된 홀드아웃이다.
- **결과를 보기 전에 기준을 적는다.** 측정마다 사전등록 문서를 먼저 커밋한다.
