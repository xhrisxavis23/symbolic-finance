# 전체 과정 기록 — 틱 데이터에서 진입 수식까지

지시받은 것은 하나다.

> 틱 데이터를 시계열 딥러닝(DeepLOB)에 넣고, 그 모델을 심볼릭 증류해서
> 간단한 수식으로 바꾼다.

이 문서는 그 하나를 하는 데 무슨 일이 있었는지를 시간 순으로 적는다.
약어 없이, 사람이 읽을 수 있게 쓴다.

---

## 0. 한 줄 요약

파이프라인은 만들어졌고 돌아간다. 수식도 나온다. **오래 걸린 것은 파이프라인이
아니라 "나온 수식을 믿어도 되는가"를 판단할 장치를 만드는 일이었다.**

그 과정에서 같은 결함이 **네 번** 나왔다:

> **자기가 공부한 데이터로 자기를 채점한다.**

고칠 때마다 한 층 위에서 다시 나타났다. 마지막에는 그 부정을 잡으려고 만든
심판 자신이 같은 부정을 저지르고 있었다.

---

## 1. 왜 곧바로 안 돌렸나

금융 데이터에서는 **그럴듯한 수식이 아주 잘 나온다.** 하루치 노이즈를 외운
수식과 진짜 시장 법칙은 겉보기가 같다.

물리학이라면 데이터에서 `F = Gm₁m₂/r²` 를 되찾아 방법이 옳음을 보일 수 있다.
금융에는 그런 정답이 없다. 그래서 **이미 답이 알려진 미시구조 법칙 5개를 먼저
되찾아 보는 관문**을 만들었다. 그걸 못 하면 미지의 수식을 찾아봐야 믿을 수 없다.

| | 법칙 | 무엇을 말하나 |
| --- | --- | --- |
| 1 | 마이크로프라이스 | 호가 불균형이 클수록 가격이 그쪽으로 움직인다 |
| 2 | 주문흐름 선형 | 매수·매도 불균형에 비례해 가격이 밀린다 |
| 3 | 집계 임팩트 | 거래량이 커질수록 충격이 제곱근꼴로 커진다 |
| 4 | 다중 스케일 변동성 | 여러 시간 규모의 변동성이 미래 변동성을 만든다 |
| 5 | 체결 군집 | 체결이 몰리면 다음 체결도 빨리 온다 |

---

## 2. 1차 실행 — 5개 중 1개

**결과: 관문 통과 실패.** 탐색 예산을 11배로 올려 다시 돌려도 같았다.
20개 트랙 중 19개가 동일한 판정이었다.

그런데 실패의 모양이 이상했다. 마이크로프라이스 법칙에서 **후보 수식 12개 중
8개가 구조적으로 옳았는데, 우리가 1등으로 고른 것만 아니었다.**

탈락 사유도 사소했다. 정답 수식에 `+0.089` 라는 작은 숫자가 붙어 대칭을 깨고
있었다. 그 숫자는 법칙의 본질을 훼손하는 대신, 학습에 쓴 데이터의 노이즈에
아주 조금 더 잘 맞는다.

**진단: 탐색의 실패가 아니라 선택의 실패다.** 정답을 찾아놓고 못 고른다.

---

## 3. 결함 1회차 — 수식 후보 선택

원인은 채점 기준이 **"학습에 쓴 데이터에 얼마나 잘 맞나"** 하나뿐이라는 것이었다.
그런데 그 데이터의 95% 는 예측 불가능한 노이즈다. **노이즈가 95% 인 데이터에서
"제일 잘 맞는 것"을 뽑으면 노이즈를 제일 잘 외운 것이 뽑힌다.**

**고침:** 종목을 둘로 나눠, 수식은 한쪽에서 만들고 채점은 **안 본 쪽**에서 한다.

**효과:**

```
마이크로프라이스 법칙의 대칭성 오차
고치기 전   0.359 / 0.325 / 0.184    3개 중 1개 통과
고친 후     1.01e-15 / 1.22e-15 / 1.07e-15    3개 전부 통과
```

`1e-15` 는 컴퓨터가 소수를 표현할 때 생기는 오차 수준이다. **사실상 완벽한
홀함수를 찾아냈다.** 진단이 옳았다.

---

## 4. 관문이 계속 막히는 이유를 따로 확인하다

법칙 3개가 여전히 실패했다. 그런데 실패 방식이 특이했다 — 셋 다 **깨끗하고
해석 가능한 결과**를 내는데 교과서 상수와만 안 맞았다.

그래서 물었다: **이 법칙들이 애초에 이 데이터에 있기는 한가?**

증류도 딥러닝도 없이, 데이터에서 곧바로 회귀로 쟀다(200종목·130만 행).

```
                    직접 측정          증류 결과
마이크로프라이스     있음 ✓            찾음 ✓
체결 군집           있음 ✓            찾음 ✓
주문흐름 선형        없음 ✗            실패 ✗
집계 임팩트          없음 ✗            실패 ✗
다중 스케일 변동성   없음 ✗            실패 ✗
```

**5개 전부 일치했다.** 증류는 실제로 있는 법칙 둘을 정확히 찾고, 없는 셋에서
정확히 실패했다. 우연히 맞은 것도, 있는데 놓친 것도 없다.

**결론: 증류가 문제가 아니었다. 관문이 이 데이터에 없는 것을 찾아오라고 하고
있었다.**

특히 집계 임팩트는 "지수가 틀렸다"가 아니라 **멱법칙 관계 자체가 없었다**
(75만 행에서 R² 0.025).

## 5. 결함 2회차 — 딥러닝 교사

DeepLOB 을 구현해 붙였다. 그런데 관문 성적이 오히려 나빠졌다.

원인을 찾아보니 교사가 **자기가 공부한 종목에서 자기 점수를 매기고 있었다.**

```
              공부한 종목    안 본 종목
마이크로프라이스   +0.860       −1.720
집계 임팩트       +0.947       −0.397
체결 군집         +0.762      −13.864
```

공부한 데이터에서는 압도적인데 안 본 데이터에서는 무너진다. 음수는 "평균을
찍느니만 못하다"는 뜻이다. **훈련 중에는 손실이 계속 내려가서 이 붕괴가
안 보인다.**

**고침:** 안 본 종목의 성적으로 학습을 멈추게 했다.

**효과:** 음수 붕괴가 전부 사라졌다(−13.864 → −0.000).

### 이때 관문의 허위 판정이 드러났다

교사를 고치자 관문이 집계 임팩트를 "복원했다"고 판정했다. 그런데:

```
              수식을 평가하면      실제 데이터는
지수              0.590              0.078
적합도 R²         0.963              0.025
```

**발견된 수식은 그럴듯한 멱법칙처럼 생겼고, 데이터에는 그 관계가 없다.**
관문이 수식의 *모양*만 보고 데이터와 대조하지 않기 때문이다.

**검증 없이 갔으면 이 수식을 진짜라고 보고했을 것이다.**

## 6. 결함 3회차 — 관문 자체를 다시 만들다

관문이 묻는 질문을 바꿨다.

```
옛 관문   "발견된 수식이 교과서 법칙처럼 생겼는가"
새 관문   "한 번도 안 본 종목에서 실제로 예측이 맞는가"
```

순환 논리를 막는 장치를 세 겹으로 넣었다 — 데이터 분리(정답 만드는 종목과
증류하는 종목이 서로소), 시점 분리(기준을 증류 실행 전에 확정), 방법 분리
(정답은 단순 회귀, 채점받는 것은 증류).

### 여기서 가짜 데이터 검사를 추가했다

정답 종목이 하나뿐이면 "측정이 고장났는데 그것만 우연히 통과"하는 경우를
못 잡는다. 그래서 **y 를 무작위로 섞은 가짜 관계**를 넣고 반드시 "신호 없음"으로
나와야 한다는 조건을 걸었다.

**이 검사가 바로 결함을 잡았다.**

```
법칙                섞은 y 에서 신호 검출
마이크로프라이스        0/5   정상
주문흐름 선형          0/5   정상
집계 임팩트            0/5   정상
다중 스케일 변동성      5/5   ← 가짜인데 신호가 있다고 함
체결 군집              0/5   정상
```

원인: 종목 안에서만 섞으면 **종목 간 수준 차이**가 남는다. 기준 모델이 잡고
있던 것은 "같은 종목 안에서 변동성이 미래 변동성을 만든다"가 아니라
**"종목마다 변동성 수준이 다르다"** 였다.

**법칙이 주장하는 것과 측정이 재는 것이 또 어긋났다.** 고쳤고, 다시 검사해
0/5 로 떨어지는 것을 확인했다.

## 7. 결함 4회차 — 심판이 정답지를 미리 봤다

새 관문을 전체 실행했다. **판정은 중단(STOP)** — 그런데 깨진 것이 대조군이었다.
우리가 참이라고 확인한 마이크로프라이스 법칙을 증류가 통과하지 못했다.

숫자를 보니 이상했다:

```
                증류    교사없음   단순회귀    기준
마이크로프라이스  0.900    0.866     0.916    [0.953, 0.979]
```

**세 방법이 전부 기준에 못 미친다.** 증류만의 문제가 아니었다.

원인:

```
기준        정답 종목 안에서 교차검증  →  정답지를 일부 보고 채점
증류 후보   다른 종목에서 배워서 채점  →  정답지를 한 번도 못 봄
```

**기준에만 홈그라운드가 있었다.** 부정을 잡으려고 만든 심판이 같은 부정을
저지르고 있었다.

지표에도 문제가 있었다. 구간 평균으로 점수를 내는 방식이 법칙마다 **2배에서
109배까지** 제각각 부풀렸다. 그 지표가 도입된 경위도 문제였다 — 정직한 지표가
"너무 엄격해서" 바꾼 것이었다. **답이 불편해서 자를 바꾼 것이다.**

**고침:**
- 기준도 후보와 **똑같은 경로**로 만든다(같은 데이터에서 배우고 같은 데이터에서 시험).
- 점수를 **실제 예측 정확도**로 바꾼다.

**효과:** 주문흐름 법칙의 기준이 0.268 → 0.111 로 2.4배 떨어졌다.
**옛 방식이 기준을 부풀리고 있었다는 직접 증거다.**

## 8. 현재 결과

```
대조군(마이크로프라이스)   통과   증류 0.044 ≥ 기준 0.024
주문흐름 선형             재현   예측 정확도 0.354
다중 스케일 변동성         재현   예측 정확도 0.493
집계 임팩트               자격 없음
체결 군집                 자격 없음
관문 판정: 통과(PROCEED)
```

### 숫자가 낮아 보이는 것은 정상이다

고칠 때마다 점수가 내려갔다. 그게 맞는 방향이다.

```
0.99  →  0.35     부정을 걷어낸 결과이지 성능이 나빠진 것이 아니다
```

틱 단위 수익률 예측에서 정확도 0.35 는 낮은 값이 아니다. 이전의 0.99 가
비정상이었다.

### 남은 구멍 두 개

**하나.** 증류 수식 자체에 가짜 데이터를 먹여본 적이 없다. 해보니
다중 스케일 변동성 수식만 가짜에서도 점수가 나온다(+0.046). 작지만 실재한다.
**기준 모델은 이 결함을 막도록 고쳤는데 수식 채점 경로는 검사한 적이 없다.**

**둘.** 집계 임팩트가 "자격 없음"으로 빠진 것은 아마 오판이다. 자격 검사가
직선 관계만 볼 수 있어서 못 본 것이지 관계가 없는 게 아닐 수 있다 —
그 수식은 0.288 을 내고 가짜 데이터 검사도 통과한다.

## 9. 이 과정에서 잡은 기술적 결함

전부 "오류가 나지 않고 조용히 잘못된 답을 내는" 종류였다.

| 결함 | 내용 |
| --- | --- |
| 역행렬이 쓰레기값 반환 | 예외 없이 `1.27e32` 를 돌려줘 한 단계가 통째로 무작동인데 오류는 하나도 안 났다 |
| 컴파일러가 상수를 버림 | `tanh(2·x)` 를 `tanh(x)` 로 번역. `0.964 ≠ 0.762`. 16개 리뷰가 전부 놓쳤다 |
| 나눗셈이 통째로 차단 | 거부 사유가 "명시적 연산자를 써야 한다"였는데 **그 연산자가 이미 있었다** |
| 어휘 부족 | 계획서의 핵심 가설을 탐색기가 문자 그대로 표현할 수 없는 상태였다 |
| 데이터의 4.2% 가 비정상값 | 행 단위로는 안 보이다가 시간 윈도우를 씌우니 손실이 통째로 무너졌다 |
| 판정 함수의 가짜 통과 | 순수 직선이 감쇠 곡선으로 통과하고 있었다 |

| "epoch 을 700 으로 올려야 공정하다" | 근거로 삼은 비교표가 **정답지를 본 수치**였다. 내가 이 프로젝트가 진단한 함정에 빠졌다 |
| "이 수정으로도 관문은 안 열린다" | 열렸다 |

그런데 이후 시간 추정에서 같은 실수를 반복했다 — 가장 빠른 법칙으로 재서 곱했다.

## 12. 갈림길 — 세 갈래

### A. 바로 본 실험을 돌린다 (권장)

지시받은 것 그대로 — 전종목 틱 데이터를 DeepLOB 에 넣고, 증류해서 **진입 조건
수식**을 뽑고, 정본 백테스트에 태운다.

- 근거: 관문이 통과를 냈다. 대칭이 잡혔고, 가짜 데이터 50회가 전부 걸러졌고,
  대조군이 통과했다. **측정 장치는 이제 믿을 만하다.**
- 남은 구멍 둘(§8)은 **본 실험을 막지 않는다.** 그것들은 관문 판정의 무게에
  영향을 주지 실험 자체를 무효로 만들지 않는다.
- 비용: 전종목 규모라 계산이 크다. 실측해서 규모를 잡아야 한다.
- 위험: 나온 수식에 §8 의 오염이 섞일 수 있다. **알고 감수하는 것과 모르고
  당하는 것은 다르다** — 알고 가는 것이다.

### B. 남은 구멍 둘을 막고 본 실험

수식 쪽 가짜 데이터 검사를 정식 관문 조건으로 올리고, 자격 검사가 비선형
관계도 볼 수 있게 고친다.

- 근거: 네 번 나온 결함이다. 다섯 번째가 없다고 볼 이유가 없다.
- 비용: 반나절 정도. 검사 추가와 재실행.
- 위험: **검증에 계속 시간을 쓰다가 정작 지시받은 것을 못 한다.** 이미 검증
  장치가 본체보다 커졌다.

### C. 여기서 정리하고 멈춘다

지금까지를 하나의 결과로 묶는다 — "심볼릭 증류는 데이터에 실제로 있는 관계를
찾아내고 없는 것은 못 찾는다. 그것을 확인하는 과정에서 자기 채점 결함을
네 번 발견하고 고쳤다."

- 근거: 방법론 검증으로는 완결된 이야기다.
- 잃는 것: **지시받은 것을 안 한 채로 끝난다.**

## 13. 내 판단

**A 를 권한다.**

검증에 쓴 시간이 이미 본체보다 길다. 그리고 검증의 목적은 "완벽한 관문"이 아니라
**"나온 수식을 믿어도 되는지 판단할 근거"** 였고, 그 근거는 이제 있다.

- 증류는 데이터에 실제로 있는 관계를 찾는다(§4 에서 5개 전부 일치로 확인).
- 가짜 데이터는 걸러진다(§6 의 50회 검사).
- 채점은 이제 대칭이다(§7).

남은 구멍 둘은 **본 실험 결과를 해석할 때 감안할 사항**이지 실험을 막을 사유가
아니다. 특히 §8 의 오염은 크기가 작고(0.046 vs 0.493) 어느 법칙에서 나타나는지도
안다.

**다만 본 실험 결과를 보고할 때 이 둘을 반드시 함께 적는다.** 모르고 지나간 것과
알고 감수한 것은 기록에서 구분되어야 한다.
