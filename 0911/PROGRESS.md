# 0911 진행 기록

## 2026-09-11 KST 10:33 — 폴더 개설

지시: (1) 3일 학습 + 1일 테스트로 데이터 규모 변경, (2) 모델을 바꾸지 않는
진단 전부 진행.

### 즉시 판단이 필요한 것 두 가지 — 실행 전에 정한다

**판정 R39 (봉인 홀드아웃을 다시 정한다):**
  앞선 실험은 `20260317` 을 봉인했는데 이번 지시로 그 날짜가 학습에 들어간다.
  봉인이 사라지므로 **남은 날짜에서 새로 정한다 — `20260420` 이후 6거래일.**
  학습·테스트·진단 어디에도 쓰지 않고 마지막에 한 번만 연다.
  봉인이 필요한 이유는 그대로다: 여러 번 시험하면 우연히 좋은 결과가 나오고
  그것을 진짜라고 착각하게 된다.

**판정 R40 (GPU 사용을 재검토한다 — 앞선 R36 을 뒤집을 수 있다):**
  0910 에서 GPU 로 옮기지 않기로 했다(R36). 근거는 두 가지였다 —
  (a) 검증 사슬 전체가 CPU 결정론 위에 세워졌다, (b) 병렬화만으로 목표 시간에 닿았다.

  **이번에는 둘 다 흔들린다.**
  (a) 이번 실험은 **3일치·다른 분할**이라 0902/0909 의 검증과 애초에 직접 비교되지
      않는다. 비교 가능성 논거가 약해졌다.
  (b) 규모가 다르다. 0910 에서 교사 학습이 20만행 21분이었다. 저마찰층 3일치는
      대략 2,400만 행이고, 선형이면 **시드당 40시간**이 넘는다. 병렬화로 안 된다.

  **따라서 이번 실측(`SCALE.md`)에서 GPU 를 정면으로 평가한다.** 쓰기로 하면
  조건을 붙인다 — 결정론 설정을 최대한 켜고, **작은 규모에서 CPU 결과를
  재현하는지 먼저 확인**한 뒤에 본 실행에 들어간다. 재현이 안 되면 안 쓴다.
