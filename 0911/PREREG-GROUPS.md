# 사전등록 — 종목군 분석

작성: 2026-09-14 KST 00:25. **종목군 기준값 분포도, 종목군별 R² 도 보기 전.**
실행 전에 커밋한다. 실행 후 이 문서를 고치면 사전등록이 아니다.

---

## 0. 무엇을 묻는가

> **교사 R² 가 낮은 것은 "모든 종목에서 조금씩 되기" 때문인가,
> "일부 종목군은 되고 일부는 전혀 안 되는 것의 평균" 이기 때문인가?**

근거: LOBFrame(Briola, Bartolucci, Aste, *Quantitative Finance* 25(7), 2025)이
같은 DeepLOB·같은 학습법으로 **큰 틱 종목 MCC 0.26 유지, 작은 틱 종목 0.01(무작위)** 을
보였다. 우리는 2,507 종목을 한 덩어리로 묶었다.

**답에 따라 다음 수가 갈린다.** 특정 종목군만 되면 → 그 종목군으로 좁히는 것이
모델 교체보다 먼저다. 전부 비슷하게 안 되면 → 종목 풀 문제가 아니다.

## 1. 0910 의 함정을 피한다 — 이 설계의 핵심

0910 에서 **저마찰층 학습 → 고마찰층 평가**를 했더니 고마찰에서 덜 잃었는데,
**아무 정보 없는 영점 기준선도 똑같이 덜 잃었다.** 모델의 성질이 아니라 **층의 성질**이었다.

같은 함정을 두 가지로 막는다.

**(a) 교사를 한 층에서만 학습시키지 않는다.** 모든 종목군을 섞어서 학습한다
(종목 무작위 분할, 종목군별 비율 유지). 그래야 종목군 차이가 "학습 분포에서 멀어서"가
아니라 "그 종목군 자체의 예측 가능성" 을 반영한다.

**(b) 모든 종목군에 기준선을 함께 잰다.** 같은 특징·같은 분할로 학습한 **선형 회귀(릿지)**
를 종목군마다 나란히 둔다.

```
기준선도 같은 종목군 기울기를 보인다   →  종목군 자체의 예측 가능성 (본질)
DeepLOB 에서만 기울기가 보인다         →  모델이 특정 종목군에서만 부가가치를 낸다
```

## 2. 종목군 정의 — 규칙으로 못박는다 (경계 숫자는 분포에서 기계적으로)

종목별 기준값은 `groups/symbol_covariates.py` 가 기준일 `20260316` 에서 잰다.
**틱은 표를 박지 않고 종목별 1~5호가 인접 간격의 최빈값**이다(PROGRESS.md 발견 1).

| 축 | 기준값 | 규칙 | 근거 |
| --- | --- | --- | --- |
| **1차: 상대 틱** | 스프레드 평균 틱 수 `mean_spread_ticks` | **3분위** (작음/중간/큼). 동률은 `frac_one_tick` 내림차순으로 끊는다 | LOBFrame 이 쓴 축. 스프레드가 1틱에 붙어 있을수록 "큰 틱" |
| **2차: 유동성** | 거래대금 `traded_value` | **3분위** | 틱과 유동성이 섞여 있을 수 있어 따로 본다 |

**두 축 다 보고한다.** 결과를 보고 둘 중 좋아 보이는 쪽을 고르지 않는다.
`tick_share < 0.5`(틱 판정이 불확실한) 종목은 분석에서 빼고 **몇 개를 뺐는지** 보고한다.

## 3. 분할 — 자기가 공부한 데이터로 자기를 채점하지 않는다

```
                     날짜 16·17·18 (학습 기간)        날짜 19 (테스트 하루)
학습 종목  (2/3)     교사 경사하강 (16·17)            평가 ②: 본 종목·안 본 날
                     조기 종료는 아래 선택 종목에서
선택 종목  (1/6)     조기 종료 전용 (18)               —
평가 종목  (1/6)     한 번도 안 봄                     평가 ①: 안 본 종목·안 본 날 ← 1차 결과
```

- 종목 분할은 **종목군(1차 축 3분위)별로 같은 비율**을 유지한다. 시드 고정.
- **1차 결과는 평가 ①** — 종목도 날짜도 안 본 경우. 평가 ② 는 날짜 일반화만 따로 본다.
- 봉인(`20260420` 이후)은 열지 않는다.

## 4. 교사·규모

- 교사: DeepLOB (0910 과 같은 구조, 병목 2). **GPU**(판정 R41), epoch 예산 1500,
  선택 종목 R² 로 조기 종료.
- 학습 표본: **200만 행 고정.** GPU 에서 수렴 확인된 규모다.
- **조건부 2차 실행 (지금 못박는다):** 표본 크기 곡선에서 200만 → 500만 사이 R² 가
  **10% 이상** 오르면 500만 행으로 한 번 더 돌려 보조로 보고한다. 이 조건은 종목군 결과를
  보기 전에 곡선만으로 판단한다.

## 5. 지표

- 종목군별 **행 단위 R²** (실측 y 에 대해). 구간 평균 지표는 쓰지 않는다 — 0909 에서
  법칙마다 2~109배 제각각 부풀림이 확인됐다.
- 신뢰구간: **종목 단위 부트스트랩** 1000회 (종목을 복원추출). 행 단위로 뽑으면 한 종목의
  행들이 서로 닮아 구간이 부당하게 좁아진다.
- 모든 종목을 합친 **전체 R²** 도 같은 방식으로 낸다.

## 6. 선결 조건 — 측정을 믿을 수 있어야 판정한다

**음성 대조군:** 종목 안에서 y 를 섞은 데이터로 같은 평가를 한다. **모든 종목군에서
R² 신뢰구간 상한 ≤ 0** 이어야 한다. 하나라도 양수면 판정하지 않고 원인부터 찾는다
(0909 에서 이 검사가 종목 간 수준 교란을 잡았다).

## 7. 판정 규칙 (1차 축, 평가 ①, DeepLOB)

| 판정 | 조건 |
| --- | --- |
| **이질성 있음** | 가장 좋은 종목군 R² 의 CI 하한 > 전체 R² 점추정, **그리고** 가장 나쁜 종목군 R² 의 CI 가 0 을 포함 |
| **이질성 없음** | 세 종목군의 CI 가 모두 서로 겹친다 |
| **애매** | 위 둘 다 아니다 — 그대로 보고하고 주장하지 않는다 |

**본질 vs 모델 판정** (위가 "이질성 있음"일 때만): 릿지 기준선도 같은 방향 기울기
(가장 좋은 종목군이 같고 CI 가 겹치지 않음)면 **본질**, 아니면 **모델 부가가치**.

## 8. 사전 예측

| | 예측 | 근거 |
| --- | --- | --- |
| 이질성 | **있음** | LOBFrame 결과. 우리 종목 풀은 NASDAQ 대형주 15개보다 훨씬 이질적이다 |
| 가장 좋은 종목군 | **큰 틱** (스프레드가 1틱에 붙은 종목) | LOBFrame 방향 |
| 본질 vs 모델 | **본질** | 0902~0910 내내 교사 품질과 결과가 무관했다 |
| 1차 vs 2차 축 | 1차(상대 틱)의 기울기가 더 뚜렷 | 틱이 직접적 기전 |

### 예측이 틀리면

- **이질성 없음** → 종목 풀을 좁혀도 안 된다. 신호 부족이 전반적이다.
- 가장 좋은 종목군이 **작은 틱** → LOBFrame 과 반대. 한국 시장 구조가 다를 수 있다 — 그대로 보고.
- **모델 부가가치** → 교사 개선이 특정 종목군에서 유효하다는 뜻. 모델 교체 기대치가 올라간다.

## 부록 A — 종목군 배정 직후, 종목군별 R² 를 보기 전에 추가한 확정 사항

작성: 2026-09-14 KST 00:35. 기준값 분포와 3분위 배정만 본 상태다(`groups/data/group_boundaries.txt`).
**어떤 R² 도 계산하지 않았다.** 아래는 결과가 아니라 분포가 드러낸 설계 문제에 대한 대응이다.

### A1. 틱과 유동성이 섞여 있다 → 2차원 분석을 보조로 등록한다

```
스프레드 틱 수 vs 거래대금 순위상관: -0.555
         저유동  중유동  고유동
큰틱       104     189     530
중간틱     274     338     211
작은틱     445     296      82
```

큰 틱 종목은 대부분 고유동이고 작은 틱 종목은 대부분 저유동이다. **1차 축(틱)에서
기울기가 나와도 틱 때문인지 유동성 때문인지 가릴 수 없다.**

**보조 분석(기술 통계, 판정 아님):** 틱 3분위 × 유동성 3분위 = 9칸의 R² 를 낸다.
유동성 3분위 **각각 안에서** 큰틱−작은틱 R² 차이의 부호가 1차 축 기울기와 같은지 본다.
- 3개 유동성 칸 중 2개 이상에서 부호가 같으면 "틱 효과가 유동성을 통제해도 남는다"로 **서술**한다.
- 평가 종목이 20개 미만인 칸은 수치만 싣고 해석에 쓰지 않는다(큰틱×저유동은 전체 104개라
  평가 종목이 약 17개로 예상된다).
- 칸이 작아 신뢰구간이 넓으므로 **이것으로 §7 판정을 뒤집지 않는다.**

### A2. 평가 행 = 테스트일의 유효 행 전체, 가중치 없음

학습 표본은 기존대로 on-manifold 선별을 쓰지만, **평가는 `20260319` 의 마스크 통과 행 전체**를
가중치 없이 쓴다. 이유: on-manifold 선별은 종목군마다 걸러내는 비율이 달라 **종목군의 모집단
자체를 바꾼다.** 묻는 것은 "실제 틱에서 예측이 되는가"다.

### A3. 음성 대조군 = 고정된 예측값 대 종목 안에서 섞은 y

재학습하지 않는다. 학습된 교사의 예측값은 그대로 두고, 평가 y 를 **종목 안에서** 무작위로
섞어 같은 종목군별 R² 를 낸다(전체 섞기도 함께). 종목 안 섞기는 종목별 y 평균을 보존하므로,
**예측값이 종목 수준 차이만 타고 있으면 R² 가 양수로 나온다** — 0909 에서 다중 스케일 변동성
기준 모델이 걸린 바로 그 교란이다. §6 대로 모든 종목군에서 CI 상한 ≤ 0 이어야 한다.

### A4. 릿지 기준선은 DeepLOB 과 같은 입력을 본다

릿지도 **같은 16스텝 윈도우 입력(19특징×16=304차원)** 을 쓴다. 현재 시점 특징만 쓰면 기준선이
구조적으로 불리해져 "모델 부가가치"를 과대평가한다. 규제 강도는 {1e-3, 1e-2, …, 1e3} 에서
**선택 종목** 성적으로 고른다(평가 종목은 보지 않는다).

### A5. 종목 분할

학습 2/3 · 선택 1/6 · 평가 1/6, **틱 3분위별로 같은 비율**, 시드 0. 38개(틱 판정 불확실)는 제외.
