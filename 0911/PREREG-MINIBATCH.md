# 사전등록 — 미니배치 학습과 3일 전체 학습

작성 시각은 이 파일을 처음 커밋한 git 커밋 시각을 따른다.
**작성 시점에 미니배치 코드는 한 줄도 없고, 미니배치 결과도 없다.** 전체 배치 종목군 실행은 적재 중이다.

---

## 0. 왜 필요한가

지시 1 은 "3일 전체를 학습, 다음 날 하루 전체로 테스트" 다. 교사는 **전체 배치** 학습이고,
메모리 실측이 10만 행당 3.83 GB(할당)라 3일 학습 종목 전체(수천만 행)는 GPU 에 올릴 수 없다.
**미니배치로 바꿔야 한다.**

---

## 1. 바꾸는 것과 바꾸지 않는 것

**바꾸는 것 — 학습 절차만:**

| 항목 | 전체 배치 (현재) | 미니배치 |
| --- | --- | --- |
| 한 번의 경사 | 학습 행 전체 | 무작위 묶음 `B = 8,192` 행 |
| 1 epoch | 경사 1회 | 학습 행 전체를 한 바퀴(경사 약 행수/8,192 회) |
| 학습률 | Adam 1e-2 | Adam **{1e-3, 3e-4} 중 선택 종목 R² 로 선택** (결과 보기 전 고정한 두 후보) |
| 데이터 위치 | GPU 에 전부 | CPU 에 두고 묶음마다 GPU 로 보낸다 |
| 윈도우 | 학습 행 전체를 미리 만든다 | **묶음마다 원본 배열에서 즉석으로 만든다**(같은 인과 윈도우 함수, 세션 경계 동일) |
| 조기 종료 평가 | 10 epoch 마다 | **0.25 epoch 마다**, 인내 20회(= 5 epoch), 상한 30 epoch |

**바꾸지 않는 것:** 모델 구조(DeepLOB, 병목 2), 입력 특징 19개, 16스텝 윈도우, 표준화 방식(학습 행
평균·표준편차), 손실(가중 MSE + 가중 BCE + L1), 가중치(on-manifold 꼬리 가중치), 조기 종료 지표
(선택 종목 가중 R²), 시드, 종목 분할(`group_run.make_split`, 시드 0).

---

## 2. 1단계 — 동등성 검증 (3일 전체 학습 전의 관문)

**질문:** 같은 데이터에서 미니배치가 전체 배치만큼 배우는가.

- 데이터: **종목군 실행과 똑같은** 학습 200만 행·가중치·선택 행 (같은 입력에 같은 시드로
  `manifold_select` 를 다시 돌리면 동일하다).
- 기준값: 종목군 실행 교사의 선택 종목 최선 R² (`groups/out/group_run_progress.json` → `teacher.best_score`).
- 미니배치로 학습해 같은 선택 종목 R² 를 잰다.

**통과 기준 (한쪽 방향):**

> 미니배치 선택 R² ≥ **전체 배치 선택 R² × 0.9**

- 미니배치가 **더 높아도 통과**다(경사 횟수가 훨씬 많으니 가능하다). 그 사실은 그대로 보고한다.
- **실패하면 3일 전체 학습으로 가지 않는다.** 학습률 후보를 늘리거나 묶음 크기를 바꿔 다시 시도하지
  않는다 — 그러면 통과할 때까지 조정하는 것이 된다. 실패를 보고하고 원인을 따로 진단한다.
- 추가로 **테스트일 평가 ① 행에서 두 교사의 예측 상관**을 보고한다(판정 아님).

---

## 3. 2단계 — 3일 전체 학습

1단계를 통과했을 때만.

```
                  20260316·17·18                 20260319
학습 종목 1,647    교사 학습 (3일 전체, on-manifold 행 전부)   평가 ②
선택 종목   411    조기 종료 (3일, 20만 행 상한)             —
평가 종목   411    —                                     평가 ① ← 1차
```

- "3일 전체" = 학습 종목 × 3일의 **on-manifold 행 전부**(상한 없음). on-manifold 선별을 빼지 않는 이유:
  학습 절차 외의 것을 바꾸지 않기 위해서다.
- 조기 종료는 **선택 종목**(학습에 안 쓴 종목)의 같은 3일에서 한다 — 학습 종목의 날짜를 떼어 쓰면
  "3일 전체 학습" 이 아니게 되고, 학습 종목으로 채점하면 자기가 공부한 데이터로 자기를 채점하게 된다.
- 평가 종목·평가일·평가 행은 **종목군 실행과 완전히 같다.**

---

## 4. 판정 — 3일 전체가 200만 행보다 나은가

두 교사는 **같은 평가 ① 행**에서 예측한다. 그러므로 두 R² 를 따로 구간 추정해 비교하지 않는다
(부록 C 교훈: 서로 독립이 아닌 양을 구간끼리·점추정끼리 비교하면 틀린다).

> **종목 단위 짝지은 부트스트랩**으로 `ΔR² = R²(3일 전체) − R²(200만 행)` 의 95% 구간을 낸다.
> 같은 부트스트랩 표본에서 두 R² 를 함께 계산해 차이를 잰다.

| 판정 | 조건 |
| --- | --- |
| **데이터 증가 효과 있음** | ΔR² 구간 하한 > 0 |
| **효과 없음** | ΔR² 구간이 0 을 포함 |
| **오히려 나빠짐** | ΔR² 구간 상한 < 0 |

**선결 조건:** 종목군 분석과 같은 음성 대조군(종목 안 섞기, 부록 E 기준)을 3일 교사 예측에도 적용한다.
위반이면 판정하지 않는다.

**구현 후 실측 전에:** 짝지은 부트스트랩 코드를 알려진 답이 있는 합성 데이터로 먼저 점검한다
(차이 없음 → 효과 없음, 한쪽에만 신호 추가 → 효과 있음). 종목군 분석에서 판정 규칙 결함 세 개를
이 방식으로 잡았다.

## 5. 사전 예측

| | 예측 | 근거 |
| --- | --- | --- |
| 1단계 동등성 | **통과** | 같은 데이터·같은 손실이고 경사 횟수가 훨씬 많다 |
| 3일 전체 vs 200만 행 | **효과 있음, 그러나 작음** | 표본 크기 곡선에서 얕은 모델이 10배 늘려 +14%, 수렴 DeepLOB 이 20만→100만 +10% |
| R² 절대 수준 | **0.03 미만** | 곡선이 100만 행에서 0.020 이고 증가가 느리다 |

**0.03 미만이면 수수료를 넘기 어렵다는 0910 결론은 바뀌지 않는다.** 그래도 "데이터를 늘리면
얼마나 나아지는가" 에 대한 측정된 답이 된다.

### 예측이 틀리면

- **1단계 실패** → 미니배치가 이 교사를 제대로 못 배운다. 3일 전체 학습은 이 교사로는 불가능하다고 보고한다.
- **효과 없음** → 데이터 부족이 R² 0.015 의 원인이 아니다. 종목군 분석 결과와 합쳐 원인을 다시 본다.
- **R² 0.03 이상** → 데이터 부족이 주 원인이었다. 0910 결론을 다시 검토해야 한다.
