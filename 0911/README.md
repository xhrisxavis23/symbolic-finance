# 0911 — 데이터 규모를 늘리고, 모델을 바꾸지 않는 진단을 전부 돌린다

## 지시받은 것

1. **데이터 크기 변경.** 하루치만 쓰지 말고 **3일 전체를 학습, 그다음 하루 전체로 테스트.**
2. **모델을 바꾸지 않는 선에서 하겠다고 말한 것 전부 진행.**
   - 종목군별 R² 재측정 (틱 크기·유동성으로 나눠서)
   - 학습 표본 크기 대비 R² 곡선

**모델은 바꾸지 않는다.** DeepLOB 교체(TLOB/MLPLOB)는 이 폴더의 결과를 보고 결정한다.

---

## 왜 이걸 먼저 하는가

앞선 실험(`../0910`)의 결론:

```
교사 R² = 0.015 (안 본 종목)   →   방향 예측력 부족   →   수수료 23bp 를 못 이김
손실의 70% 가 방향 오류. 비용 문제는 13%뿐.
```

그런데 **R² 0.015 가 왜 낮은지 두 가지 후보가 구분되지 않는다.**

| 후보 | 근거 | 이 폴더에서 어떻게 가리나 |
| --- | --- | --- |
| **데이터가 부족했다** | 교사가 저마찰층 가용 행의 **2.4%** 만 봤다 (8,151,756 중 198,007). `max_samples=200,000` 상한 때문 | 3일치로 늘리고, 표본 크기 대비 R² 곡선을 잰다 |
| **종목 풀이 이질적이다** | LOBFrame(Briola et al. 2025): 같은 모델·같은 학습법인데 큰 틱 종목 MCC 0.26 유지, 작은 틱 종목 0.01(무작위). 우리는 2,507종목을 한 덩어리로 묶었다 | 종목군별로 나눠 R² 를 다시 잰다 |

**둘 다 모델을 바꾸지 않고 답을 준다.** 그리고 둘 다 답이 "아니오"면,
그때 모델 교체의 기대 효익이 실제로 높아진다.
