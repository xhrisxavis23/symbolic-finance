## 2. 저하 곡선 — 구현자의 해석을 정정한다

구현자는 "L→M→H 가 저하가 아니라 개선된다, 사전 예측과 반대"라고 보고했다.
**총액으로 보면 그렇지만, 그 해석은 틀렸다.**

### 의사결정당 손익 (bps/decision) — 정규화한 값

```
            L(학습층)   M(선택층)   H(봉인층)
시드 0       -2.444     -1.829     -1.772
시드 1       -0.980     -0.576     -0.415
시드 2       -0.974     -0.528     -0.460
나이브       -1.193     -0.781     -0.797
영점         -1.773     -1.240     -1.222
```

**정규화해도 L→M→H 로 개선된다.** 그런데 결정적인 것은 이것이다 —

> **기준선도 똑같이 개선된다.** 나이브 −1.193 → −0.797, 영점 −1.773 → −1.222.

**즉 L→M→H 개선은 전략의 성질이 아니라 층의 성질이다.** 다섯 계약 전부에서
같은 방향으로 나타나고, 아무 정보도 없는 영점 기준선에서도 나타난다.
**우리 방법의 일반화 능력에 대해 아무것도 말해주지 않는다.**

왜 저마찰 종목에서 더 크게 잃는가: 비용은 23bp 로 고정인데 손실의 주 원인이
**방향 오류**다. 유동성 높은 종목일수록 정보 트레이더가 빠르므로 역선택이
심하다 — 이 방향으로 해석하면 자연스럽다.

**따라서 사전 예측(§9.2)이 "빗나갔다"고 기록하는 것은 부정확하다.
예측이 상정한 축(방법의 외삽 성능)이 이 데이터에서 측정되지 않았다는 것이
정확한 서술이다.**

## 3. 그래도 있는 신호 — 과장하지 않고 적는다

### 3-1. 순위가 세 층에서 일관되다

```
시드1 ≈ 시드2  <  나이브  <  영점  <  시드0        (덜 잃는 순)
```

이 순서가 L·M·H 세 층 모두에서 동일하다. **시드 1·2 의 수식은 나이브 기준선보다
의사결정당 약 45% 덜 잃는다**(−0.42~−0.46 vs −0.78~−0.80). 층이 바뀌어도 유지된다.

순수 잡음이면 순위가 층마다 흔들려야 한다. 흔들리지 않는다.

### 3-2. 서로 다른 시드가 같은 구조에 도달했다

```
시드 1   tanh(호가불균형 + 공격적주문흐름20 + 스프레드비율)
시드 2   tanh(호가불균형 + 큐불균형·주문흐름20 + 주문흐름100 + 스프레드비율)
```

독립적으로 돌린 두 탐색이 **호가 불균형 + 체결 흐름 + 비용비를 tanh 로 묶는**
같은 형태에 도달했다. 사전 예측(§9.5)이 맞았다.

### 3-3. 손실의 원인이 특정된다

원장 코호트 분해:

```
PERSISTENT_ADVERSE (방향 자체가 틀림)     체결의 70~84%
COST_INSUFFICIENT (방향은 맞는데 비용 못 넘김)   6~13%
```

**비용에 먹힌 것이 아니라 방향을 못 맞춘다.** 이것이 이번 실험의 가장 값진
진단이다. 비용 문제라면 임계를 조이거나 보유를 늘려 개선할 여지가 있지만,
방향 예측력 자체가 약하면 그런 조정으로는 안 된다.

시드 1·2 의 PERSISTENT_ADVERSE 비중(70%대)이 나이브·영점(78~83%)보다 낮다 —
방향을 조금 더 맞힌다. 그 "조금"이 45% 덜 잃는 것으로 나타나지만,
**흑자로 돌리기에는 모자란다.**

## 4. 게이트 실패와 경제성 실패는 같은 원인인가

구현자가 이 질문을 남겼다. **다른 문제로 보인다.**

- 게이트가 실패한 것은 **체결확률 헤드**의 보정이다(주문이 체결될 확률).
- 경제성이 실패한 것은 **가격 방향** 예측이다(사면 오르는가).
- 그리고 **역선택 부호 검사는 세 시드 모두 통과**했다 — 이것이 둘을 잇는
  다리였다면 여기서도 이상이 나왔어야 한다.

즉 **두 개의 독립적인 약점**이고, 둘 중 경제성 쪽이 더 근본적이다.
체결확률을 완벽히 보정해도 방향을 못 맞히면 여전히 잃는다.

## 5. 이번 실험이 실제로 답한 것

**답한 것:**
- 파이프라인은 끝까지 돈다. 틱 데이터에서 진입 수식이 실제로 나온다.
- 나온 수식은 **경제적으로 말이 되는 형태**이고 시드 간에 재현된다.
- 그 수식은 나이브 기준선보다 **일관되게 덜 잃는다** — 세 층 전부에서.
- **그러나 흑자가 아니다.** 그리고 실패의 원인은 비용이 아니라 **방향 예측력**이다.

**답하지 못한 것:**
- **증류가 기여했는가.** ablation 을 이번 회차에서 뺐으므로 "증류 없이도 같은
  결과가 나오는지" 모른다. 0902 에서는 증류를 빼는 쪽이 더 나은 경우가 있었다.
- **외삽 성능.** §2 에서 본 대로 L→M→H 축이 층 효과에 가려 측정되지 않았다.
- **익일 일반화.** 봉인 홀드아웃을 열지 않았다(열 조건 미충족).

**알고 감수한 것** (`README.md` 에 실행 전 명시):
- 증류 수식의 오염 검사가 관문 조건이 아니다.
- 자격 검사가 곡선 관계를 못 본다.

## 6. 이번에도 조용한 버그를 잡았다

기준선 분류가 **부분문자열 포함**으로 판단해서, 영점 기준선
`book_imbalance_velocity` 가 나이브 `book_imbalance` 를 포함하는 바람에 둘 다
나이브로 분류됐다. 영점 바구니가 비어 **모든 시드가 "영점을 못 이김"으로 자동
실패**할 뻔했다 — 진짜로 못 이겨서가 아니라 비교 대상이 사라져서.

최종 판정 직전에 잡았다. 재생 자체는 정확했으므로 2.5시간짜리를 다시 돌리지
않고 라벨만 고쳤다.

**이것으로 이 프로젝트에서 "오류 없이 조용히 틀린 답을 내는" 결함이 일곱 번째다.**

## 8. 뒤늦게 드러난 구멍 — 학습에 쓴 데이터가 2.4% 다

대화 중 "어떤 틱 데이터를 썼나"는 질문에 답하다 확인했다.

```
저마찰층(교사 학습층) 가용 행    8,151,756
실제 교사 학습에 쓴 행             198,007    ← 2.4%
```

규모 실측에서 DeepLOB 학습이 20만행 21분 / 100만행 1.9시간으로 늘어나는 것을 보고
`max_samples = 200,000` 상한을 걸었다(`DESIGN.md` §1).

**그래서 R² = 0.015 가 (a) 모델 용량 부족인지 (b) 데이터를 2.4% 만 봤기 때문인지
구분되지 않는다.** §5 "답하지 못한 것"에 이 항목을 빠뜨렸다 — 여기 추가한다.

이것은 모델 후보 조사(`MODEL-CANDIDATES.md`)의 권고 순위에도 영향을 준다:
새 모델을 붙이기 전에 **같은 모델로 학습 표본을 늘렸을 때 R² 가 움직이는지**부터
보는 것이 더 싸고 결정적이다. 안 움직이면 모델을 바꿔도 안 움직일 가능성이 높다.

→ `MODEL-CANDIDATES.md` §10 의 1순위(종목군별 재측정) 옆에 **동급 우선순위**로
   "학습 표본 크기 대비 R² 곡선"을 둔다. 둘 다 모델을 바꾸지 않고 답을 준다.
