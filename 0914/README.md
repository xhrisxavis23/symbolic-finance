# 0914 — 교사 자체는 돈을 버는가

## 지시 (2026-09-14 KST 15:06)

> 교사 모델 성능 측정 방식을 **수익이 되는지 안 되는지**로 먼저 따진다.
> 1단계·2단계 모두 진행하고 md 로 기록한다. HTML 보고서를 고치고 GitHub 에 바로 반영한다. 30분마다 점검한다.

## 왜

증류 수식은 교사를 흉내 낸 것이다. **교사 자체가 정본 계약에서 벌지 못하면 수식이 벌 이유가 없다.**
그런데 0902~0911 은 교사를 R² 로만 쟀고, 교사 자체의 손익은 한 번도 재지 않았다(`0910/PREREG.md:32` 에서 범위 밖으로 뺐다).

R² 는 수익과 다른 곳을 본다:

```
y_path ≈ −1 + (30초 BID1 상승폭) / (스프레드 + 23bp)

매수가 이익  ⇔  y_path > 0  ⇔  30초 안에 스프레드 + 23bp 이상 오른다   ← 분포의 오른쪽 꼬리
R²          =  전체 행의 제곱오차                                        ← 분포의 몸통
```

  **vendor 파일은 바꾸지 않는다** — 교사 점수는 실행 프로세스 안에서만 주입한다.
