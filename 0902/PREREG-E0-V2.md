# 사전등록 — E0 게이트 v2 (평가 규칙 교체 + DeepLOB 교사)

작성 시각: 2026-09-05, **결과를 보기 전**.
이 문서는 실행 전에 커밋한다. 실행 후 이 파일을 고치면 사전등록이 아니다.

---

## 0. 왜 새 사전등록인가

E0 v1 은 두 번 돌아 두 번 다 `stop` 이었다(1/5, 거부권 발동). 그 결과를 **보고 나서**
진단을 얻었다 — 정답이 후보 명단에 있는데 우리 채점표가 다른 걸 1등으로 뽑는다.

그 진단을 근거로 채점 규칙을 바꾸는 것은 **새 실험**이다. v1 의 판정을 소급해서
뒤집는 것이 아니다. v1 의 `stop` 은 그대로 기록에 남는다.

---

## 1. 무엇을 바꾸는가 (정확히 이것만)

### 1-1. 후보 선택 규칙 — 표본 내 → 표본 외

현재 (`sd/e0/runner.py:_fit_track`):

```python
primary_index = int(np.argmax([c.in_sample_score for c in candidates]))
judged = [_judge(law, c.expr, names, X) for c in candidates]   # X = 적합에 쓴 그 데이터
```

문제: 교사 R² 가 0.05~0.58 인 데이터에서 "적합에 쓴 데이터에 제일 잘 맞는 것"을 뽑으면
**노이즈를 제일 잘 외운 후보**가 뽑힌다. v1 에서 실제로 관측된 탈락 사유가 정확히
그 모양이었다 — 정답 수식에 `+0.089` 오프셋 하나가 붙어 대칭을 깨는 대신 이번 데이터에
아주 조금 더 잘 맞았다.

변경 후:

- **종목 단위로 분할한다.** 적합 종목 집합과 선택 종목 집합은 서로소.
  분할은 `seed` 로 결정론적이며, 층화 구조를 유지한다(각 층에서 같은 비율로 나눈다).
- SR 적합은 **적합 종목**으로만 한다.
- 후보 점수는 **선택 종목**에서 계산한다. `primary_index` 는 그 점수의 argmax.
- `_judge` 도 **선택 종목**의 X 로 수행한다. 게이트가 형태 판정을 적합 데이터에서
  계산한 값으로 내리는 일이 없어야 한다.

**분할 축을 종목으로 잡은 이유:** 우리가 싸우는 실패 양상(`+0.089` 같은 종목 고유
노이즈 암기)이 종목 단위로 발생하고, 이 연구의 본 주장이 "종목을 가로질러 이식되는
진입 조건"이기 때문이다. 시간 축 분할은 같은 종목의 노이즈를 양쪽에 남긴다.

### 1-2. 교사 — ShallowMLP → DeepLOBCompact

현재 교사는 3층 MLP(`Linear(n,32) → ReLU → Linear(32,bottleneck)`)다.
계획서가 예정한 `DeepLOBCompact` 로 교체하고, **두 교사를 모두 돌려 비교**한다.

## 2. 바꾸지 않는 것

- `sd/e0/criteria.py` 의 판정 함수와 밴드 — **한 바이트도 바꾸지 않는다.**
  (L3 지수 밴드 [0.4, 0.7] 포함. v1 에서 0.804 가 나온 것을 보고 넓히지 않는다.)
- 게이트 규칙: 5개 중 **3개 이상** 복원 → 진행 / **2개 이하** → 중단 /
  **L1·L2 동시 실패** → 거부권.
- 심사 대상은 **최고점수 후보 하나**(`primary`). `any_candidate` 로 바꾸지 않는다.
  — 그렇게 바꾸면 v1 에서 이미 통과했을 것이고, 그것이 체리피킹이다.
- seed 0, 층화 구조, 날짜 `20260316`.
- 봉인 홀드아웃 `20260317` 이후는 **열지 않는다.** 표본 외 분할은 같은 날 안의
  종목 분할로만 만든다.

## 3. 사전 예측 (반증 가능하게 적는다)

v1 에서 관측된 `any_candidate_recovered`(main 트랙) 를 근거로 한 예측:

| | 법칙 | v1 정답이 후보에 | **예측** | 근거 |
|---|---|---|---|---|
| L1 | 마이크로프라이스 | 있음 (8/8 트랙) | **복원된다** | 선택만 고치면 되는 사례 |
| L2 | OFI 선형 | main 없음 / ablation 있음 | 불확실 | 판단 보류 |
| L3′ | 집계 임팩트 | 없음 (전 트랙) | **여전히 실패** | 생성 문제 — 채점으로 해결 불가 |
| L4′ | 다중 스케일 RV | 없음 (전 트랙) | **여전히 실패** | 생성 문제 — 채점으로 해결 불가 |
| L5 | Hawkes | 있음 | **복원 유지** | v1 에서 이미 복원 |

**예상 게이트 결과: 2~3 / 5.** 즉 이 수정만으로 게이트를 통과한다는 보장이 없고,
경계선에 걸릴 가능성이 높다. 그래도 그대로 간다.

### 이 예측이 틀리면

- **L1 이 여전히 실패하면 내 진단이 틀린 것이다.** "선택의 실패"라는 설명을 버리고
  다시 진단해야 한다. 채점 규칙은 원인이 아니었다는 뜻이다.
- **L3·L4 가 복원되면** "생성 문제"라는 구분이 틀린 것이다.

두 경우 모두 그대로 보고한다.

### 교사에 대한 예측

v1 에서 교사 R² 와 복원 여부는 **아무 관계가 없었다** — 가장 나쁜 교사(L5, R²=0.023)가
복원됐고 가장 좋은 교사(L2, R²=0.580)가 실패했다.

**예측: DeepLOB 으로 교사를 올려도 게이트 판정은 바뀌지 않는다.**

이 예측이 맞으면 "교사는 현재 병목이 아니다"가 확인된다. 틀리면 — 즉 DeepLOB 에서
복원 수가 늘면 — 내 판단이 틀린 것이고 그대로 보고한다. 어느 쪽이든 값이 나온다.

---

## 4. 실행 계획

1. 평가 규칙 교체 → 기존 교사(ShallowMLP)로 E0 실행. **v1 과 이것만 다르다.**
2. DeepLOBCompact 구현 → 같은 평가 규칙으로 E0 실행.
3. 세 실행(v1 / v2-shallow / v2-deeplob)을 나란히 비교한다.

`niterations` 는 v1 재실행과 같은 **200**. 규모를 낮춰 돌리고 판정하지 않는다.

---

## 5. 금지 사항 (v1 과 동일)

- 결과가 나쁘게 나오면 설정을 바꿔 다시 돌리는 것.
- 잘 나온 seed 를 고르는 것.
- 판정 밴드를 결과에 맞춰 조정하는 것.
- 교사를 특정 법칙에 맞춰 튜닝하는 것.

**한 번 돌리고 나온 대로 보고한다.** `stop` 이 또 나오면 `stop` 이라고 쓴다.
